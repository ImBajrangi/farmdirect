## Route Authentication & Navigation Architecture

- **Role Switcher in Header**: The header contains an interactive 3-way segmented role selector (`Buyer`, `Farmer`, `Admin`). Switching roles updates `AuthContext` state without page reload, allowing instant auditing of permissions.
- **Client Fallback Logic**: In local testing environments without connected Supabase credentials, the application automatically mounts demo/mock datasets (e.g. Patil Agro Orchards for Farmers, Super Admin for Governance), ensuring zero blocked routes during evaluation.
